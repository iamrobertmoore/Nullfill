05 The contract

Three rules. Each one is a line you can read.

No owner, no fee, OpenZeppelin SafeERC20 and ReentrancyGuard. 46 tests, four fuzzed, and a test that the bytecode on chain is exactly this source.

1

Anyone can unwind an expired escrow.

Getting money back never depends on one party being able to send a transaction.

function unwind(bytes32 ref) external nonReentrant {
    // ...no check on who the caller is
    if (block.timestamp < o.deadline) revert NotYetUnwindable(ref, o.deadline);
    o.status = Status.Unwound;
    o.token.safeTransfer(o.unwindTo, o.amount);
2

The refund address is named up front.

Set when the escrow opens, changeable while it's open, never discovered too late.

address recovery = unwindTo == address(0) ? msg.sender : unwindTo;

3

No deadline inside the 24 hour window.

Acting on a missing transaction before the window closes is the bug. The contract refuses.

uint64 public constant FORCE_INCLUSION_WINDOW = 24 hours;
uint64 earliest = uint64(block.timestamp) + FORCE_INCLUSION_WINDOW;
if (deadline < earliest) revert DeadlineTooSoon(earliest);

09 What this won't claim

Limits, stated before anyone finds them.

  • A failure receipt can't tell you why. A revert and a force-included transaction that was forcibly failed both leave a failure receipt, no logs and burned gas.
  • Screening is only directly visible at submit time. If you didn't send it, you can't be certain it was screened rather than never sent.
  • The restricted list is private. Addresses are stored as salted hashes. Nothing here tries to reverse it.
  • Nullfill can't route around screening. Every transfer it makes is screened like any other. It changes who has to act, and when it's safe to act.
  • The deployed escrow assumes exact-transfer tokens. USDG and the testnet stock tokens all are. The guard for fee-on-transfer tokens ships with the next deployment.

The escrow is free. The watcher is next.

Nullfill Watch will keep a screened transaction as a signed receipt, since the sender's error is the only record that exists, and track every deadline and bridge deposit. $99 a month per desk.
